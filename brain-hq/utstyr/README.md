# C.E.S. / Feltesken

Spillerens toolbox er **Burp Suite Community Edition**, **netcat** og **Gobuster**. Den medfølgende wordlisten ligger i [kodeordliste.txt](kodeordliste.txt).

Les verktøyenes manualer og innebygde hjelp for å lære hvordan de brukes:

```sh
man gobuster
gobuster --help
man nc
nc -h
```

Se [spillerbriefen](../README.md) for oppstart, spilleregler og øvrig praktisk informasjon.
